# Customer Churn Analysis

## Project Overview

This project analyzes customer churn data to identify the key factors associated with customer retention and churn.

The analysis was performed using Python, Pandas, Matplotlib, and exploratory data analysis techniques.

## Objectives

- Understand the overall customer churn rate
- Analyze churn across customer demographics and services
- Identify customer groups with higher churn risk
- Generate business insights that can help improve customer retention

## Key Analysis

The project explores the relationship between churn and:

- Customer tenure
- Contract type
- Internet service
- Senior citizen status
- Gender
- Monthly charges
- Customer service and security features

## Key Findings

- Overall churn rate is approximately **26.54%**
- Month-to-month customers have a significantly higher churn rate than customers with one-year or two-year contracts.
- Customers with shorter tenure have a higher likelihood of churn.
- Fiber optic customers show a higher churn rate compared with DSL customers.
- Senior citizens have a higher churn rate than non-senior customers.
- A high-risk segment of **1,188 customers** was identified with a churn rate of approximately **64.48%**.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- Exploratory Data Analysis (EDA)

## Project Files

- `Customer_Churn_Analysis.ipynb` — Complete analysis and visualizations
- `customer_churn_cleaned.csv` — Cleaned dataset used in the analysis

## Conclusion

The analysis shows that contract type, customer tenure, internet service, and monthly charges are important factors associated with customer churn. These insights can help businesses identify high-risk customers and develop targeted retention strategies.
